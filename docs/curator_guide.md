# ブランド登録の手引き

このアプリで登録していただいた内容が、enmono の提案のもとになります。

**アプリ** https://enmono-curator.streamlit.app/

開くと合言葉を尋ねられます。合言葉は別途お伝えします。

## 入力するのは4つだけ

| 項目 | 内容 |
|---|---|
| ブランド名 | そのままお書きください |
| 公式サイトのURL | `https://` から始まる形で |
| このブランドをおすすめする理由 | **ここがいちばん大事です** |
| おすすめの商品、そのURLと理由 | 思い当たるものがあれば。なくても構いません |

カテゴリ・価格帯・タグなどは入力不要です。公式サイトを見れば分かることは、こちらで機械的に集めます。

## おすすめの理由について

ホームページに書いてあることの写しは必要ありません。**なぜあなたがそれをおすすめするのか**、思ったことをそのまま書いてください。ここは機械には書けない部分で、この情報そのものが提案の質を決めます。

書き方の例：

> 修理しながら永く使うことを前提に作っている。職人が一本ずつ手で仕上げていて、直して使う文化そのものを掲げている。

長さは自由です。一行でも構いませんし、思うところがあれば長く書いていただいても構いません。

## 2つのタブの使い分け

**知っているもの**
もともとご存じで、贈り物としておすすめできるブランド。まずはこちらから埋めてください。

**見つけたもの**
調べていて出会い、ピンときたブランド。知っているものが出尽くしたら、こちらに移ってください。このタブでは「なぜピンときたのか」が最も価値のある情報になります。ご存じなかったのに良いと思えた、その判断の理由を知りたいためです。

## おすすめの商品について

ブランド全体が良い場合と、特定の商品にそのブランドらしさが出ている場合があります。後者だと感じたときに書いてください。

たとえば「このケーキ屋さんは全体的に良いというより、ショートケーキが特別」というような場合です。空欄でも問題ありません。

商品ごとに、商品名・商品ページのURL・おすすめする理由を書けます。URLは分かる範囲で構いません。

商品は何点でも書けます。「＋ 商品を追加」を押すと入力欄が1組増えます。要らなくなったものは右の ✕ で消せます。

## すでに登録されているブランドの場合

同じブランドが既に入っている場合は、登録時に画面でお知らせします。そのまま登録することもできますが、その場合はあなたの理由が既存の情報に追記される形になります。

## 登録したあとで直したいとき

「登録した一覧」タブに、これまで登録したものが1行ずつ並びます。理由は途中まで表示され、続きは編集を開くと読めます。

各ブランドの「編集」を押すと、その行の下に入力欄が開きます。ブランド名・URL・理由・おすすめの商品をその場で直して、「この内容で更新する」で保存されます。

削除も同じ場所にあります。押すとブランド名を出して確認を求めるので、そこで「削除する」を選んだときだけ消えます。消したものは戻せません。内容を入れ替えたいだけのときは編集をお使いください。

## 保存について

「登録する」を押した時点で保存されます。まとめて送る操作は要りません。

保存先に繋がらないときは、画面の上に赤い帯で「データベースに繋がっていません」と出ます。**この表示が出ているときは入力しないでください。** 打った内容が残らないためです。表示が出たらご連絡ください。

「書き出し」タブから、登録した内容をCSVで取り出すこともできます。
